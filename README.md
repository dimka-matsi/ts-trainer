# Тренажёр TypeScript

Подготовка к собеседованию по TypeScript: карта из девяти регионов по порядку TypeScript Handbook, уроки с песочницей и упражнениями, которые проверяет настоящий компилятор TypeScript прямо в браузере.

Сейчас готовы регионы «Основы» (10 уроков), «Болото союзов» (6 уровней сортировщика) и «Мастерская утилит» (8 уроков, все 22 utility types).

```bash
npm install
npm run dev       # http://localhost:5173
npm run verify    # проверить все упражнения компилятором
npm run build
```

Устройство проекта и правила добавления контента — в `CLAUDE.md`, учебный план — в `docs/curriculum.md`.
