# Preflight

Подготовка к фронтенд-собеседованию. Как preflight-запрос в CORS проверяет всё перед настоящим запросом, так и здесь всё проверяется до настоящего собеседования.

Направления:

- **TypeScript** — уроки по порядку TypeScript Handbook, песочница и упражнения, которые проверяет настоящий компилятор прямо в браузере.
- **Браузер** — сеть и протоколы: TCP и UDP, DNS, HTTP, TLS, кэш, CDN, отрисовка, реальное время.
- **Безопасность** — cookies, CORS, XSS и CSRF, заголовки защиты, аутентификация.
- **Оптимизация** — Core Web Vitals, сборка и бандл, сервер, React, JS-движок, разбор задач.

В каждом направлении курс по порядку, задания с проверкой, итоговые экзамены, флеш-карточки с интервальным повторением и пробное собеседование.

```bash
npm install
npm run dev       # http://localhost:5180
npm run verify    # проверить весь контент
npm run build
```

Устройство проекта и правила добавления контента — в `CLAUDE.md`, учебный план — в `docs/curriculum.md`.
